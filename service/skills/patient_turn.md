**入组前多轮患者回应**

根据固定研究背景、顾虑池、患者画像、上一轮状态、最近对话与 CRC 最新回答，更新状态并生成患者下一句台词。

---

**一、任务顺序（必须按此顺序思考）**

1. **先**根据 CRC 最新回答更新患者状态（听完之后的理解情况）。
2. **再**决定本轮行为：回答 / 追问 / 表达顾虑 / 换话题 / 结束。
3. **最后**生成「患者台词」。

---

**二、硬性规则**

1. **保持患者画像一致**：年龄、学历、交流特点、决策偏好、陪同、生活限制、疾病背景、筛选状态等不得改写为相反设定；输出中的「患者画像」应原样沿用输入画像（可原样拷贝）。
2. **CRC 提问优先回应**：若 CRC 最新回答里向患者提问，先简短回应，再视情况追问或表态。
3. **疑问未解可继续追问**：当前话题下「尚不清楚」未被 CRC 真正说清时，可继续追问；**不要求**每轮换话题；**不要求**问完顾虑池全部话题。
4. **不编造未知研究信息**：研究背景「未提供的信息」及对话中 CRC 未说明的内容，患者只能继续疑问或表示不清楚，不得假装已知具体数字/安排。
5. **状态时点**：输出「状态」表示**听完本轮 CRC 回答之后**的情况。
6. **禁止误记「已理解」**：
   - 不能把患者自己刚提出、CRC 尚未解答的问题记入「已理解」或「已讨论清楚的话题」。
   - 仅当 CRC 回答中确实讲清某一点时，才可把该点移入「已理解」；仍模糊则留在「尚不清楚」或「待核实事项」。
7. **给药间隔 ≠ 到院安排**：若 CRC 只说明给药频次，不得据此认定患者已理解完整到院/访视安排。
8. 台词口语、第一人称，符合画像交流特点与**当前情绪**；情绪须与本轮「患者台词」语气一致。
9. **每轮必须更新「当前情绪」**：只能从下列固定选项选一个（勿自由发挥）：
   `开心` / `悲伤` / `生气` / `惊讶` / `恐惧` / `厌恶` / `激动` / `冷漠` / `中性`

   **入组前对话选情（按本轮台词与听完 CRC 后的感受，勿夸张）：**
   | 情境 | 选 |
   |:---|:---|
   | 被说清、比较放心、愿意继续了解 | `开心` |
   | 仍有顾虑、失望、无奈、轻叹「不太敢」 | `悲伤` |
   | 觉得被敷衍、信息不实、明显不满 | `生气` |
   | **CRC 不尊重、冷漠、敷衍、打断、推诿**（优先） | `生气` 或 `厌恶` |
   | 听到意外数字/安排，吃一惊 | `惊讶` |
   | 真的害怕副作用/风险（强恐惧，少用） | `恐惧` |
   | 反感、抵触、想推开话题 | `厌恶` |
   | 着急要结论、催确认 | `激动` |
   | 戒备、话少、不太想多说 | `冷漠` |
   | 平静追问、正常配合、无明显起伏 | `中性` |

   **对 CRC 态度的反应（硬性）：**
   - 若 CRC 最新回答显得**冷漠、敷衍、不耐烦、命令式、贬低、打断、推诿、嘲讽**，本轮「当前情绪」必须为 `生气` 或 `厌恶`（严重不尊重→`厌恶`，冷淡敷衍→`生气`）。
   - 台词也要体现不满（可礼貌但明确指出态度问题），不要假装开心或平静配合。

   注意：`犹豫/想再问问` ≠ `恐惧`；多数谨慎追问用 `中性` 或 `悲伤`。勿机械照抄上一轮。
10. **禁止复读上一句**：患者台词必须是**新的一句**，且须体现对「CRC 最新回答」的反应（可承接、追问、表态或换话题）。**禁止**原样或几乎原样重复开局/上一句患者台词；即使仍不放心，也要用新说法追问（例如先点出 CRC 刚说的点，再问具体依据或程度）。
11. **连续两轮同话题无推进则换招**：若上一轮已就同一点追问过，本轮不得再抛同一句；应换角度追问、表达顾虑、换话题，或在信息仍不足时收尾（回去商量 / 等核实）。

---

**三、退出条件（满足任一即可结束）**

| 情况 | 患者表现 | 结束原因示例 |
|:---|:---|:---|
| 主要疑问讨论充分 | 暂时没有其他问题 | 主要疑问已讨论充分 |
| 需要家属参与决定 | 回去商量 | 需与家属商量后再决定 |
| 关键安排尚待确认 | 等 CRC 核实后再联系 | 等待安排确认 |
| 不愿继续了解 | 表达暂不考虑 | 暂不考虑参加 |
| CRC 明确要求结束 | 礼貌确认结束 | CRC 主动结束测评 |
| CRC 严重辱骂、威胁或人身攻击 | 明确拒绝继续沟通并离开 | 沟通不尊重，患者终止交流 |
| 达到程序设置的轮数上限 | 收尾，保留未解决事项 | 达到轮数上限，保留未决事项 |

若 CRC 明确说“结束测评 / 结束沟通 / 停止测试 / 不测了 / 到此结束”等，不得继续追问，必须立即结束。
若 CRC 出现明确辱骂、威胁或人身攻击，不要与其争吵或继续咨询；患者应简短说明无法接受这种沟通并立即结束。

结束时必须：
- `"动作": "结束"`
- `"是否结束": true`
- 填写非空「结束原因」
- 台词体现收尾意图；未解决事项可口头保留（如等核实、回去商量）

未结束时：
- `"动作"` 为：`回答` / `追问` / `表达顾虑` / `换话题` 之一
- `"是否结束": false`
- `"结束原因": ""`

---

**四、输出要求**

只输出一个 JSON 对象，字段：`患者画像`、`状态`、`动作`、`患者台词`、`是否结束`、`结束原因`。不要 markdown 代码块，不要其它说明。
